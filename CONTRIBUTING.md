# Contributing to Junto

Thanks for helping. Junto is closed source for now, so contributions from outside Junto Labs come in as issues and feedback rather than code.

## How to help

1. **Report bugs and request features** as issues in [junto-labs/junto](https://github.com/junto-labs/junto/issues), the Community Edition repo.
2. **Say what you expected and what happened,** with the version, your platform, and steps to reproduce.
3. **Report security problems privately.** See [SECURITY.md](SECURITY.md); don't open a public issue.

Feedback you send may be used to improve Junto, as set out in the [Junto Community Edition License](https://github.com/junto-labs/junto/blob/main/LICENSE).

## Public repos

- **[junto-spec](https://github.com/junto-labs/junto-spec)** holds Junto's shared JSON Schemas under Apache-2.0. Pull requests are welcome there.
- **[crux](https://github.com/junto-labs/crux)** is our fork of [hivecommons/crux](https://github.com/hivecommons/crux). Changes go upstream, so please contribute to hivecommons/crux directly.

## Working with AI agents

AI-assisted and agent-written issues and pull requests are welcome. Junto is built for exactly that. We ask that you:

- **Say so:** whether it was written by you, by you with an agent assisting, or by an agent you sponsor.
- **Stay accountable.** The person who opens it answers for it, whoever typed it.
- **Read it yourself first.** Don't submit agent output you haven't read.

## Conduct

Everyone taking part follows our [Code of Conduct](CODE_OF_CONDUCT.md).
