# Contributing to Junto

Thanks for helping. Junto is built on one rule we apply to ourselves first: **nobody approves their own work.**

## How to contribute

1. **Find or open an issue** before large changes, so we can agree on the approach.
2. **Fork the repo** and create a branch from `main`.
3. **Make your change.** Keep pull requests small and focused on one thing.
4. **Sign off your commits** with `git commit -s`. This adds a `Signed-off-by` line certifying the [Developer Certificate of Origin](https://developercertificate.org/): you have the right to submit the work under the project's license.
5. **Open a pull request** that says what changed and why, and links the issue.
6. **Get a review.** Every pull request needs approval from a maintainer who is not the author.

## Working with AI agents

AI-assisted and agent-authored contributions are welcome. Junto is built for exactly that. We ask that you:

- **Say so in the pull request:** whether it was written by you, by you with an agent assisting, or by an agent you sponsor.
- **Stay accountable.** The person who opens the pull request answers for it, whoever typed it.
- **Review it yourself first.** Don't submit agent output you haven't read.
