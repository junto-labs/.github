# junto-labs/.github

This repo holds the Junto Labs organization profile and the default community files for every repo in the org.

- [`profile/README.md`](profile/README.md) is the page shown at [github.com/junto-labs](https://github.com/junto-labs).
- [`CONTRIBUTING.md`](CONTRIBUTING.md) and [`SECURITY.md`](SECURITY.md) apply to any Junto Labs repo that doesn't have its own.

Docs and updates: [juntolabs.dev](https://juntolabs.dev)
